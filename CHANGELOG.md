# Changelog

## [1.0.0] - 2026-10-23

First release of **Amity Toolkit**, which combines four earlier standalone addons:

- **Bar Text** (was AlwaysBarText): always-on health / resource text formatted as `100/200 50%` on the player, target and target-of-target frames.
- **Auction Item Level** (was AuctionItemLevel): sortable iLvl column in the auction house browse results.
- **LFG Role Filter** (was LFGRoleFilter): Tank / Healer / DPS filter buttons in the Looking For Group browse list.
- **Overpower Alert** (was OverpowerAlert): movable Overpower icon with a 5 second countdown when your target dodges (warriors).

New:

- Minimap button and panel to switch each module on or off (`/amity`).
- Addon compartment entry.
- All settings live in one saved variable (`AmityDB`). Settings from the standalone addons are not carried over.
